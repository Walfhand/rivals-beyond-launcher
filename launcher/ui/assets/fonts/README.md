# Bundled typefaces

The launcher uses the website's Spectral display face and Alegreya Sans body face offline.

- Spectral, normal 600 — Google Fonts CSS API, `https://fonts.gstatic.com/s/spectral/v15/rnCs-xNNww_2s0amA9vmtl3G.ttf`
- Alegreya Sans, normal 400 — `https://fonts.gstatic.com/s/alegreyasans/v28/5aUz9_-1phKLFgshYDvh6Vwt3V0.ttf`
- Alegreya Sans, normal 700 — `https://fonts.gstatic.com/s/alegreyasans/v28/5aUu9_-1phKLFgshYDvh6Vwt5eFImE0.ttf`

Downloaded 2026-09-14. License notices are included as `Spectral-OFL.txt` and
`AlegreyaSans-OFL.txt`, from the corresponding `ofl` directories in
`https://github.com/google/fonts`. The font binaries are unmodified.
